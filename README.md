1.Basic Information 
Title of the project : Instant Poem/Song Generator 

Name of the Students :  Subhankar Manna 

2.Introduction and Background  
Many students find it difficult to remember complex science topics and definitions. This             
project aims to make learning easier and more interesting by converting important science 
concepts into short poems or rhymes. The web application allows users to select a topic and 
instantly generates a simple poem along with the textbook definition.  
3.Objectives of the Project 
• To simplify difficult science topics through rhymes and poems. 
• To make learning more engaging and enjoyable for students. 
• To develop an interactive web application using HTML, CSS, and JavaScript. 
• To help students revise important concepts quickly and effectively. 
4.Problem Statement 
Students often struggle to memorize science definitions and concepts using traditional 
learning methods. This project provides a creative solution by using poems to improve 
understanding and memory retention. 
5. Methodology 
• HTML is used to create the webpage structure.  
• CSS is used to design the dark-themed glassmorphism interface.  
• JavaScript is used to implement the dynamic poem generator functionality.  
• Users can select a science topic from a dropdown menu, and the corresponding poem and 
definition are displayed instantly. 
6. Expected Outcomes  
• A fully functional interactive poem generator web application.  
• Easier and faster revision of science topics for students.  
• A fun and engaging learning experience.
